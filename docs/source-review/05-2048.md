# 2048 소스 리뷰

> **파일**: `app/2048/index.tsx`  
> **핵심 주제**: 이동 알고리즘, 애니메이션과 로직의 분리, PanResponder(스와이프)

---

## 게임 개요

4×4 보드에서 타일을 상하좌우로 밀면 같은 숫자끼리 합쳐집니다. 2048 타일을 만들면 승리.  
스와이프 제스처와 방향 버튼 두 가지로 조작할 수 있습니다.

---

## 타일 데이터 구조

```typescript
interface TileData {
  id: number;       // 각 타일의 고유 ID (애니메이션 추적용)
  value: number;    // 2, 4, 8, 16 ... 2048
  row: number;      // 현재 행 (0~3)
  col: number;      // 현재 열 (0~3)
  merging?: boolean;  // 합쳐져서 사라질 타일인지 여부
}
```

> **왜 id가 필요한가요?**  
> 타일이 합쳐질 때 "어떤 타일이 어디로 이동해서 사라지는지" 애니메이션으로 표현하려면,  
> 각 타일을 개별적으로 추적해야 합니다. 단순히 숫자 배열(number[][])만 써선 부족합니다.

## 이동 알고리즘 — moveTiles 함수

가장 복잡한 부분입니다. 왼쪽 이동(left)을 예시로 설명합니다:

```typescript
function moveTiles(tiles: TileData[], dir: Direction): MoveResult {
  // dir = 'left'인 경우

  for (let r = 0; r < SIZE; r++) {    // 각 행을 처리
    // 이 행의 타일만 꺼내서 열 순서대로 정렬
    const rowTiles = tiles
      .filter(t => t.row === r)
      .sort((a, b) => a.col - b.col);
    // 예: [col=1(값4), col=2(값4), col=3(값8)]

    let pos = 0;   // 왼쪽부터 채울 위치
    let i = 0;

    while (i < rowTiles.length) {
      const targetCol = pos;   // 이동할 목표 열

      // 인접한 두 타일 값이 같으면 합치기
      if (i + 1 < rowTiles.length &&
          rowTiles[i].value === rowTiles[i + 1].value) {

        // survivor: 값이 두 배가 되어 남는 타일
        const survivor = { ...rowTiles[i], value: rowTiles[i].value * 2, col: targetCol };
        // consumed: 합쳐져서 사라질 타일 (같은 위치로 이동 후 제거)
        const consumed = { ...rowTiles[i + 1], col: targetCol, merging: true };

        result.push(survivor, consumed);
        score += survivor.value;
        i += 2;   // 두 타일을 동시에 처리했으므로 2칸 이동
      } else {
        // 합칠 타일이 없으면 그냥 왼쪽으로 이동
        result.push({ ...rowTiles[i], col: targetCol });
        i++;
      }
      pos++;
    }
  }
}
```

> **...rowTiles[i]** 이 표현은 JavaScript/TypeScript의 **스프레드(spread) 연산자**입니다.  
> Java로 치면 `new TileData(rowTiles[i])` — 객체를 복사하는 것입니다.

## 이동 후 처리 순서 — 애니메이션과 상태 분리

```typescript
const handleMove = useCallback((dir: Direction) => {
  setTiles(prev => {
    const { newTiles, toRemove, mergedIds, score: gained, moved } = moveTiles(prev, dir);
    if (!moved) return prev;   // 변화 없으면 그냥 리턴

    isAnimating.current = true;

    // 1단계: 타일 슬라이드 애니메이션 (110ms)
    const slideAnims = newTiles.map(tile => {
      const anim = animMap.current.get(tile.id);
      return Animated.timing(anim.pos, {
        toValue: { x: tileX(tile.col), y: tileY(tile.row) },
        duration: SLIDE_DURATION,
        useNativeDriver: true,
      });
    });

    Animated.parallel(slideAnims).start(() => {
      // 슬라이드 완료 콜백 (110ms 후 실행)

      // 2단계: 합쳐진 타일 pop 애니메이션 (80ms × 2)
      toRemove.forEach(id => animMap.current.delete(id));  // 사라진 타일 제거
      // pop: 1.0 → 1.2 → 1.0 크기

      // 3단계: 새 타일 등장 (spring 애니메이션)
      // 4단계: 점수 업데이트, 승리/게임오버 체크
    });

    return newTiles;  // 즉시 상태 업데이트 (애니메이션은 별도로)
  });
}, [wonAcknowledged, createTile]);
```

> **핵심**: 상태(tiles)는 즉시 업데이트하고, 시각적 애니메이션은 별도로 처리합니다.  
> 애니메이션이 끝나는 콜백(`.start(() => { ... })`) 안에서 다음 작업을 체인으로 연결합니다.

## 스와이프 감지 — PanResponder

```typescript
const touchStart = useRef({ x: 0, y: 0 });

const panResponder = useRef(PanResponder.create({
  // 터치 시작 시 좌표 기록
  onPanResponderGrant: e => {
    touchStart.current = { x: e.nativeEvent.pageX, y: e.nativeEvent.pageY };
  },

  // 터치 끝날 때 방향 판단
  onPanResponderRelease: e => {
    const dx = e.nativeEvent.pageX - touchStart.current.x;  // 가로 이동량
    const dy = e.nativeEvent.pageY - touchStart.current.y;  // 세로 이동량

    // 30px 미만은 스와이프가 아닌 탭으로 간주
    if (Math.abs(dx) < 30 && Math.abs(dy) < 30) return;

    // 가로와 세로 중 더 많이 움직인 방향으로 처리
    if (Math.abs(dx) > Math.abs(dy)) {
      handleMove(dx > 0 ? 'right' : 'left');
    } else {
      handleMove(dy > 0 ? 'down' : 'up');
    }
  },
})).current;

// JSX에서 보드에 적용
<View {...panResponder.panHandlers}>
```

## 게임오버 판단 — canMove

```typescript
function canMove(tiles: TileData[]): boolean {
  const g = tilesToGrid(tiles);  // TileData[] → number[][] 변환

  for (let r = 0; r < SIZE; r++) {
    for (let c = 0; c < SIZE; c++) {
      if (g[r][c] === 0) return true;          // 빈 칸이 있으면 이동 가능
      if (c + 1 < SIZE && g[r][c] === g[r][c+1]) return true;  // 오른쪽과 합칠 수 있음
      if (r + 1 < SIZE && g[r][c] === g[r+1][c]) return true;  // 아래쪽과 합칠 수 있음
    }
  }
  return false;  // 빈 칸도 없고 합칠 수 있는 쌍도 없음 → 게임오버
}
```

## 요약

| 개념 | 역할 |
|------|------|
| `TileData.id` | 각 타일을 개별 추적하여 애니메이션 연결 |
| `Map<id, Animated>` | 타일 ID → 애니메이션 변수 매핑 |
| `moveTiles()` | 순수 함수로 이동 결과만 계산 (부수효과 없음) |
| `Animated.parallel` | 여러 타일을 동시에 이동 |
| `.start(callback)` | 애니메이션 완료 후 다음 작업 체인 |
| `PanResponder` | 스와이프 제스처 감지 |
| `Record<number, T>` | TypeScript의 타입 있는 객체 맵 |
